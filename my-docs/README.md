# Autobase - 自架設 PostgreSQL 高可用性叢集

Autobase 是一個開源的自動化資料庫平台，專門用於部署和管理高可用性 PostgreSQL 叢集。它提供了雲端託管資料庫服務（如 Amazon RDS、Google Cloud SQL、Azure Database）的開源替代方案。

## 🎯 專案概述

**Autobase for PostgreSQL®** 是一個完整的資料庫即服務 (DBaaS) 解決方案，讓您可以在自己的基礎設施上建立和管理與雲端服務商相媲美的資料庫服務，同時保持完全的控制權和較低的成本。

### 核心特色
- **替代雲端託管資料庫**：開源替代方案，無需依賴雲端服務商
- **自動化管理**：簡化部署、故障轉移、備份、升級等操作
- **生產就緒**：適合企業級生產環境使用
- **成本效益**：大幅降低資料庫運營成本
- **無專業門檻**：讓沒有專業資料庫管理經驗的團隊也能輕鬆使用

## 🏗️ 系統架構

### 核心組件
- **Patroni**：PostgreSQL 高可用性和自動故障轉移管理
- **etcd/Consul**：分散式協調服務 (DCS)，負責叢集協調和配置管理
- **HAProxy**：負載平衡器，提供流量分發和負載平衡
- **pgBouncer**：連接池管理，優化資料庫連接
- **pgBackRest/WAL-G**：備份和還原解決方案
- **TLS 憑證管理**：自動生成和管理安全憑證

### 支援平台
- **作業系統**：Red Hat、CentOS、Ubuntu、Debian 等 Linux 發行版
- **部署環境**：專用實體伺服器、虛擬機器、容器環境
- **雲端平台**：AWS、Google Cloud、Azure、DigitalOcean、Hetzner 等

## 🚀 主要功能

### 部署功能
- **新叢集部署**：一鍵部署完整的高可用性 PostgreSQL 叢集
- **etcd 叢集部署**：自動設置分散式協調服務
- **Consul 叢集部署**：提供替代的協調服務選項
- **負載平衡器部署**：配置 HAProxy 進行流量管理

### 維護功能
- **配置管理**：動態調整叢集設定、使用者、資料庫、擴充功能
- **滾動更新**：最小化停機時間的系統更新
- **版本升級**：PostgreSQL 主要版本的自動升級
- **自動故障轉移**：檢測故障並自動切換到備用節點

### 擴展功能
- **動態擴展**：向現有叢集新增 PostgreSQL 或協調服務節點
- **負載平衡器擴展**：新增 HAProxy 節點以提升可用性
- **水平擴展**：支援讀取副本的動態添加

### 管理功能
- **叢集清理**：完全移除叢集和相關服務
- **節點移除**：從叢集中安全移除特定節點
- **備份還原**：自動化的備份策略和災難恢復
- **監控告警**：整合 Netdata 進行效能監控

## 🛠️ 技術實作

### 模組化設計
Autobase 採用模組化架構，包含 40+ 個專業化角色 (Roles)：

**系統配置類**：
- `firewall` - 防火牆規則管理
- `hostname` - 主機名稱設定
- `timezone` - 時區配置
- `locales` - 語言環境設定
- `ntp` - 時間同步服務

**安全性類**：
- `authorized_keys` - SSH 金鑰管理
- `tls_certificate` - SSL/TLS 憑證管理
- `sudo` - 權限管理

**PostgreSQL 相關**：
- `patroni` - Patroni 高可用性配置
- `postgresql_users` - 資料庫使用者管理
- `postgresql_databases` - 資料庫管理
- `postgresql_extensions` - 擴充功能管理
- `pgbouncer` - 連接池配置

**備份還原**：
- `pgbackrest` - pgBackRest 備份解決方案
- `wal_g` - WAL-G 備份工具
- `pg_probackup` - PostgreSQL 專業備份工具

### 容器化支援
- 提供完整的 Docker 容器映像檔
- 包含所有必要的 Ansible 依賴和工具
- 支援多雲平台的 CLI 工具整合

### 自動化特性
- **智慧故障檢測**：自動檢測節點故障並執行故障轉移
- **自動備份排程**：可配置的備份策略和保留政策
- **滾動更新**：無停機或最小停機時間的更新部署
- **動態配置**：運行時配置變更，無需重啟服務
- **健康檢查**：持續監控叢集健康狀態

## 📋 快速開始

### 系統需求
- **作業系統**：Ubuntu 20.04+ / CentOS 8+ / RHEL 8+
- **記憶體**：每節點最少 4GB RAM
- **儲存空間**：根據資料量規劃，建議使用 SSD
- **網路**：節點間低延遲網路連接

### 安裝步驟

1. **安裝 Ansible Collection**
```bash
ansible-galaxy collection install vitabaks.autobase
```

2. **準備清單檔案**
根據範例 inventory 檔案配置您的主機清單

3. **執行部署**
```bash
ansible-playbook -i inventory vitabaks.autobase.deploy_pgcluster
```
